 Usa el MISMO correo de tu cuenta de GitHub.

git config --global user.name "Nombre Apellido"
git config --global user.email "tu_correo@ejemplo.com"

 Verificar:

git config --global --list


gh auth login

 Responde con las flechas y Enter:
   Where do you use GitHub?                          -> GitHub.com
   What is your preferred protocol?                  -> HTTPS
   Authenticate Git with your GitHub credentials?    -> Y
   How would you like to authenticate?               -> Login with a web browser

 En la TERMINAL aparece un código de 8 caracteres (ejemplo: A1B2-C3D4).
 No llega por correo ni por notificación: cópialo de la terminal.
 Presiona Enter, pega el código en la página que se abre y autoriza.

 Verificar:

gh auth status

 Debe decir: Logged in to github.com account TU_USUARIO

 Si el código caducó (15 minutos), presiona Ctrl + C y repite: gh auth login
